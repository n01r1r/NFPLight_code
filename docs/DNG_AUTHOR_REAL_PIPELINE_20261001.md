## Network operations and attributes

The active real estimator uses width32; encoder block counts `[2,2,4,8]`, middle12, decoder counts `[2,2,2,2]`. Each encoder stage stores its skip tensor and downsamples using a stride2 kernel2 convolution. Encoder feature shapes are32×256²,64×128²,128×64²,256×32²; the middle is512×16². Decoder upsampling is a bias-free kernel1 convolution followed by PixelShuffle2, then skip addition and NAF blocks. Denoiser architecture and its Softplus output are excluded from this execution.

The real estimator's albedo/specular intros map30→32 and3→32, respectively. Each branch has the same four encoder widths and512×16² middle tensor. The albedo decoder upsamples its middle with its own encoder skips and a tanh head produces six channels (diffuse3, specular3). The other decoder starts with concatenated specular/albedo middle tensors1024×16² and uses concatenated skips; it returns64×256² and a tanh head produces normal3+roughness1. Output concatenation reorders these heads into normal3, diffuse3, roughness1, specular3. For256×256 there is no padding/cropping change to the spatial data; the final slice preserves the input extent.

Each shared NAFBlock uses `DW_Expand=2`, `FFN_Expand=2`, dropout0 (Identity), and channelwise per-pixel LayerNorm2d epsilon1e−6. First path: LayerNorm →1×1 convolution C→2C →3×3 depthwise convolution →SimpleGate (split halves, elementwise product) →simplified channel attention (spatial average +1×1 convolution) →1×1 convolution → learned beta residual. Second path: LayerNorm →1×1 convolution C→2C →SimpleGate →1×1 convolution → learned gamma residual. All convolution/normalization/residual parameters come from strict original checkpoint loading, not fresh initialization. Evaluation mode and no-grad leave dropout disabled and prevent parameter updates.
